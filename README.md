# お絵描きマルチプレイ広場

リアルタイムでみんなと遊べるお絵描きゲームが3種類集まったWebアプリです。  
Firebase Realtime Database を使ってリアルタイム同期しています。

## ゲーム一覧

### 🍎 リアルタイム絵しりとり
前の人の描いた絵を見て、しりとりをつなげていくゲームです。  
お絵描き中の生中継モニター付きで、待ち時間も楽しめます。

### ✏️ スピードお絵描きクイズ
1人がお題に沿って絵を描き、他のプレイヤーがチャットで答えを推測します。  
一番早く正解した人が高得点！

### 📞 お絵描き伝言ゲーム
「絵を描く → 推測する → 絵を描く → 推測する」を繰り返し、  
最後にどんな言葉に伝わったかを楽しむゲームです。

## 使い方

1. ブラウザで `index.html` を開く（またはホスティング先にアクセス）
2. 名前とルームIDを入力して入室
3. フレンドをコードで追加して招待できます

## 技術スタック

- HTML / CSS / JavaScript（バニラJS）
- [Firebase Realtime Database](https://firebase.google.com/products/realtime-database)（リアルタイム同期）
- Firebase SDK v10.8.0（CDN経由）
